# 验证结果

日期：2026-09-16。平台：macOS arm64。仿真器：Icarus Verilog 12.0。

## 实际运行

执行 `./run.sh`，退出码为 0；最终编译无警告，仿真输出为：

```text
PASS: 454400 vectors, max_relative_error=1.880847190378e-06, worst_x=c27ebb4a (-63.682899475098)
```

- 去重输入总数：454,400；固定随机种子：20260916。
- 每个样本均验证 RTL 与 Python 定点模型逐位一致。
- 每个样本均验证 RTL 输出相对于双精度 `math.exp` 参考的相对误差 ≤ 1e-5。
- 样本最大相对误差：1.8808471903782198e-6。
- 最坏样本输入：-63.682899475097656，位编码 `c27ebb4a`。
- 该样本输出位编码：`118b959c`。
- 全区间保守分析上界：2.0200885968936613e-6，文档采用向上留余量的 2.03e-6。

样本含 ±64、±0、次正规数、极小正规数、指数切换点、每个查表边界及相邻的 FP32 输入、两种随机分布。
所有样本按固定种子打乱后连续送入组合单元。仿真每次等待 1ns 仅用于传播稳定，不代表硬件延迟或目标周期。

另用 `iverilog -g2005 -Wall -s exp_fp32 -t null rtl/exp_fp32.v` 确认设计文件独立通过 Verilog-2005 编译；只有 testbench 使用 SystemVerilog 仿真特性。
检查设计文件不含 if、always、initial、时钟或 TIE_FLOP 实例，存在七个指定格式的流水线注释。
所有信号依赖均从输入向输出，无回授或状态存储。

## 产物

- `build/vectors.json`：模型统计与误差预算。
- `build/model.log`：数值模型运行输出。
- `build/compile.log`：最终编译日志（无警告时为空）。
- `build/simulation.log`：RTL 仿真输出。
- `build/vectors.txt`：输入位编码、模型输出位编码、数学参考值。

再次运行脚本会覆盖这些生成产物。`build/` 和本地工具目录已加入 `.gitignore`。

## 验证边界

没有逐个穷举全部合法 FP32 位编码；全区间精度依赖设计文档中的解析误差预算及位宽上界。
没有 TIE 编译、综合、门级仿真、功耗/面积测量或静态时序分析。
七拍方案是待插入寄存器的建议；实际可达频率及流水线旁路对齐需在 TIE 环境继续验证。
区间外输入与 NaN/Inf 未作为验收对象，也没有保证其行为。
