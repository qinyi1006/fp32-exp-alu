# FP32 exp(x) 设计方案

## 接口与适用范围

`exp_fp32` 的 `x[31:0]` 和 `y[31:0]` 均为 IEEE 754 binary32 位编码。
验收范围为所有有限 FP32 输入 x ∈ [-64,64]，包括正负零和次正规数。
输出 exp(x) 在该区间内均为正的正规数，不需要输出溢出/下溢处理。
区间外、NaN 和 Inf 尚未约定，本版不保证这些输入的输出含义；不增加特殊值处理电路。

设计文件只有组合数据通路，不包含 if、always、时钟、状态或反馈。每笔输入独立计算。
所有 RTL 信号均为普通位向量，不使用 signed 声明、$signed 转换或有符号字面量。需要表达负数时显式构造补码。
建议插入七级流水线，启动间隔 1 拍，填充后每拍产生一个输出。不采用迭代或跨输入复用乘法器。
当前交付的组合 RTL 自身没有七拍延迟；注释标出后续 TIE 插入寄存器的位置。

## 算法选择

令 y = x log2(e)，k = floor(y)，f = y-k。进一步分解 f = j/32+r，j ∈ [0,31]，0 ≤ r < 1/32。
于是 exp(x) = 2^k × 2^(j/32) × 2^r。

查表保存 32 个 2^(j/32) 的定点常数，用二次多项式近似剩余部分：

    2^r ≈ 1 + r × (ln(2) + r × ln(2)^2/2)

二次 Taylor 近似的相对误差上界为 (ln(2)/32)^3/6 ≈ 1.694e-6。
同样的二次式配 16 项表，上界约 1.355e-5，精度预算不足；64 项表可以提高精度，但增加表容量。
16 项表配三次式也可满足精度，不过多一个乘法依赖层。这里采用 32 项表与二次式，兼顾表容量和运算层数；尚未进行工艺相关面积比较，不声称这是全局面积最优。

## 定点实现与位宽

本文 Q24 表示数值为整数编码除以 2^24，不表示总位宽。
所有乘法均保留完整积，再显式取位；均可直接翻译为整数乘加。

| 信号/运算 | 位宽 | 定义 |
|---|---:|---|
| magnitude / negative | 31 / 1 | abs(x)×2^24 向下截断，范围 0 到 2^30；符号独立保存 |
| log_product | 62 | magnitude × 1549082005；常数为 round(log2(e)×2^30) |
| log_integer | 32 | log_product[61:30]，幅值乘积向下取整 |
| y_q24 | 32 位补码编码 | 按输入符号及低 30 位余数构造，向负无穷取整 |
| k | 8 位补码编码 | y_q24[31:24]，数学值范围 -93 到 92 |
| j | 5 | y_q24[23:19] |
| r_q24 | 19 | y_q24[18:0] |
| table_q24 | 25 | round(2^(j/32)×2^24)，最高位恒为 1 |
| c2_product | 41 | r_q24 × 4030332（22 位常数） |
| t_q24 | 24 | 11629080 + floor(c2_product/2^24) |
| h_product | 43 | r_q24 × t_q24 |
| h_q24 | 19 | floor(h_product/2^24)，即多项式减 1 |
| correction_product | 44 | table_q24 × h_q24 |
| mant_q24 | 25 | table_q24 + floor(correction_product/2^24) |

FP32 转换：指数域 E、有效数整数 S；正规数的 Q24 幅值为 S×2^(E-126)。
E ≥ 126 时左移，否则右移。小于 2^-24 的输入截成零，误差已计入预算。
次正规数直接得到零。正负零都输出精确的 1.0。

令 P 为幅值乘积，A=P[61:30]，R=P[29:0]。正输入直接使用 A；负输入需要 floor(-P/2^30)：R=0 时为 -A，R≠0 时为 -A-1。
因此负输入的 32 位补码编码为 `(~A) + (R == 0)`，加法固定在 32 位内；零也能正确得到零。
这一余数修正保留原先算术右移的向负无穷取整行为。直接对 A 取负会把带余数的负输入误改成向零取整。
将 y_q24 按二进制补码拆分后，k 是 floor(y)，低 24 位仍为非负 f。
尾数 Q24 转为 Q23 使用最近偶数舍入，并处理舍入到 2.0 时的指数进位。
指数域为 k+127，加上尾数舍入进位，符号位固定为 0。
RTL 将 k 的最高位复制一次，得到 9 位补码编码 `{k[7], k}`，再以普通 9 位加法加 127 和进位。模 512 的结果就是所需指数，在合法输入范围内为正值，无需类型转换。
这里的最近偶数仅指最终定点尾数打包，整体算法不承诺正确舍入的 IEEE exp。

最终乘法使用 T×h 再加 T，而不是 T×(1+h)，将变量乘法从 25×25 缩至 25×19。
所有多项式系数和表项均为正，各级对 r 单调；取 j=31、r=524287 可得 t≤11755027、h≤367343、校正量≤718943、mant_q24≤33554373<2^25。因此表中各级位宽不会在合法输入下溢出，尾数始终位于 [1,2)。
表通过五层均衡三目选择树实现，避免 32 项串行优先选择。表逻辑容量为 32×25=800 位；最高位恒定，实际可变内容为 768 位。
主要算术资源为两次常数乘法（31×31、19×22）和两次变量乘法（19×24、25×19），另有移位器、加法器、余数检测和选择逻辑。
实际面积取决于 TIE 转译与综合结果，不提供未经综合的门数。

## 误差预算

记 q=2^-24，L=ln(2)，C=1549082005/2^30。
范围缩减的绝对误差满足：

    |y_hat - x/L| ≤ q/L + 64×|C-1/L| + q = D

对应指数值的相对误差 ≤ exp(LD)-1 ≈ 1.142e-7。
内部多项式定点误差（两个系数舍入、两个乘积截断）满足：

    H ≤ (1/32)×(q/2 + (1/32)×q/2 + q) + q ≈ 6.243e-8

Taylor 相对余项 B ≤ (L/32)^3/6。
表舍入绝对误差 ≤ q/2；校正乘积截断绝对误差 < q；最终尾数舍入绝对误差 ≤ q。
由于归一化的理想尾数至少为 1，可以用这些绝对误差保守地界定相对误差。
将各项及范围缩减的乘性效应合并：

    Pmax = 1 + L/32 + (L/32)^2/2
    A = B + H + (q/2)×(Pmax+H) + q
    total ≤ (exp(LD)-1) + exp(LD)×(A+q) < 2.03e-6 < 1e-5

脚本 `scripts/verify_model.py` 可复算该界。该推导覆盖整个约定区间，不依赖随机样本命中最坏点；它是实数误差分析，不是形式化工具证明。

## 建议流水线及旁路对齐

每行末尾对应一个 `// please add tie pipe here`。插入时必须同时寄存“跨级保留”列中的信号；不能只寄存乘法结果。

| 级 | 本级计算 | 级末寄存/跨级保留 |
|---|---|---|
| 1 | FP32 → Q24 幅值及符号 | magnitude, negative |
| 2 | 幅值常数乘法、负数余数修正，拆 k/j/r | k, j, r_q24 |
| 3 | 查表、r×C2 | k, r_q24, table_q24, c2_product[40:24] |
| 4 | 加 C1 得 t | k, r_q24, table_q24, t_q24 |
| 5 | r×t，取 h | k, table_q24, h_q24 |
| 6 | T×h，截取校正量 | k, table_q24, correction_product[43:24] |
| 7 | 加 T、舍入、指数修正、FP32 打包 | y |

这里只约定七次前向寄存边界。没有目标频率、工艺库和 TIE 环境，不能确认各级满足实际时钟；尤其第 2 级常数乘法与第 7 级加法/舍入需要后续时序检查。
如其中一级需要再拆分，可用第 8 拍，但需同步延迟所有旁路信号。组合仿真验证功能，不验证加寄存器后的延迟或时序收敛。

## 验证方法

Python 生成定点模型输出与独立 `math.exp` 双精度参考。testbench 同时检查 RTL 与模型逐位一致，以及 RTL 对数学参考的相对误差 ≤ 1e-5。
覆盖区间端点、正负零、次正规数、FP32 指数切换、每个查表/整数范围分界附近的相邻 FP32 值、均匀实数随机输入、均匀位编码随机输入。
固定随机种子 20260916，方便重现。样本并非所有 FP32 输入的穷举，最大误差要求另由上面的全区间误差预算支持。
